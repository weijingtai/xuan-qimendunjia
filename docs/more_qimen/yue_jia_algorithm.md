# 月家奇门排盘算法

> 本文档是月家奇门排盘的算法事实清单，作为 `extra_hour_plans.md` Phase 3 的实现依据。
>
> **权威事实依据**：[`qimen_jia_comparison.md`](./qimen_jia_comparison.md)（用户 2026-04-30 提供的四家终极对照表）。当本文与对照表冲突时以对照表为准。
>
> **核心结论**：月家与年家**完全同源**（对照表"一句话总结" §2），唯一差异是驱动柱与起局机制；本文与 `nian_jia_algorithm.md` 的 §5-§9 一致。
>
> 创建时间：2026-04-30

## 0. 盘法

**飞盘（飞宫法）**（对照表 §一），与时家"转盘"机制不同。
所有排盘步骤（地盘奇仪、天盘九星、人盘八门、神盘八神）均在 9 个固定宫位间逐宫飞布，不进行整盘旋转。

## 1. 用星

- **九星：与时家相同**（天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英）—— **直接复用 `NineStarsEnum`**
- 八门：休、生、伤、杜、景、死、惊、开（同时家）
- 八神：值符、螣蛇、太阴、六合、白虎、玄武、九地、九天（同时家）

## 2. 阴阳遁

**月家只用阴遁，无阳遁**（对照表 §一）。

## 3. 月干支推算（节气分界 + 五虎遁）

### 月支（按节气分界）

| 节气 | 月支 |
| --- | --- |
| 立春 起 | 寅月 |
| 惊蛰 起 | 卯月 |
| 清明 起 | 辰月 |
| 立夏 起 | 巳月 |
| 芒种 起 | 午月 |
| 小暑 起 | 未月 |
| 立秋 起 | 申月 |
| 白露 起 | 酉月 |
| 寒露 起 | 戌月 |
| 立冬 起 | 亥月 |
| 大雪 起 | 子月 |
| 小寒 起 | 丑月 |

### 月干（五虎遁，由年干推寅月干）

| 年干 | 寅月起 |
| --- | --- |
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

寅月之后按 60 甲子顺推到目标月。

## 4. 三元定起局宫（5 年一元，按年支孟仲季）

| 年支组 | 三元 | 起局 |
| --- | --- | --- |
| 寅、申、巳、亥（孟年） | 上元 | **坎 1 宫** 起甲子戊 |
| 子、午、卯、酉（仲年） | 中元 | **兑 7 宫** 起甲子戊 |
| 辰、戌、丑、未（季年） | 下元 | **巽 4 宫** 起甲子戊 |

## 5. 布地盘三奇六仪（阴遁逆布）

布序：戊 → 己 → 庚 → 辛 → 壬 → 癸 → 丁 → 丙 → 乙

- 起局宫放戊，**九宫逆飞**（宫号递减；阴遁逆布）
- 中 5 宫：**寄坤 2 宫**

## 6. 定值符与值使（双驱：干 + 支）

1. 找**月干所在旬首**（六甲：甲子 / 甲戌 / 甲申 / 甲午 / 甲辰 / 甲寅）
2. 旬首在地盘的落宫 → 该宫的本位九星 = **值符**，本位八门 = **值使**

### 宫位 ↔ 九星本位 ↔ 八门本位

| 宫号 | 九星 | 八门 |
| --- | --- | --- |
| 1 | 天蓬 | 休 |
| 2 | 天芮 | 死 |
| 3 | 天冲 | 伤 |
| 4 | 天辅 | 杜 |
| 5 | 天禽 | 中宫无门 |
| 6 | 天心 | 开 |
| 7 | 天柱 | 惊 |
| 8 | 天任 | 生 |
| 9 | 天英 | 景 |

## 7. 排天盘九星（值符随月干）

1. 找**地盘月干所在宫** = 目标宫
2. 值符星飞至目标宫
3. 其余九星按九宫**逆飞**：蓬 → 芮 → 冲 → 辅 → 禽 → 心 → 柱 → 任 → 英

## 8. 排人盘八门（值使随月支）

1. 值使从其本宫起，**逆数到月支宫**
2. 其余八门**逆排**：休 → 生 → 伤 → 杜 → 景 → 死 → 惊 → 开

## 9. 排神盘八神（小值符随大值符）

顺序：值符、螣蛇、太阴、六合、白虎、玄武、九地、九天

- 大值符（天盘所在宫） → 小值符落此宫
- 其余八神**逆排**

## 10. 与时家的结构性差异

- 盘法：**飞盘**（时家是转盘）
- 只用阴遁（时家阴阳都用）
- **驱动列分离为月干（值符）+ 月支（值使）双驱**，不是时家的单 jiazi 驱动
- 起局宫由年支孟仲季三元决定，不依赖节气三元
- 九星集合复用 `NineStarsEnum`，是 4 家中**唯一不需新增星集**的家

## 10b. 与年家的关系

> **月家 = 年家**（对照表 §10）：星、门、神、排盘规则完全一致，仅时间尺度与起局机制不同。

| 维度 | 月家 | 年家 |
| --- | --- | --- |
| 驱动柱 | 月柱 | 年柱 |
| 三元周期 | 12 年（按年支孟仲季） | 60 年×3 = 180 年 |
| 起局映射 | 孟→坎 1 / 仲→兑 7 / 季→巽 4 | 上元→坎 1 / 中元→巽 4 / 下元→兑 7 |

工程上：月家 / 年家**共用同一排盘器** `GanZhiDrivenQiMenPan` + 同一星集 `NineStarsEnum`。
