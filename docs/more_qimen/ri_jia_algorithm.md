## 0. 盘法

**飞盘（飞宫法）**（对照表 §一），与时家"转盘"机制不同。
所有排盘步骤（八门、九星）均在 9 个固定宫位间逐宫飞布，不进行整盘旋转。

## 1. 用星 / 用神（对照表 §二、§七）

- **九星（日家专属，与时家不通用）**：太乙 → 摄提 → 轩辕 → 招摇 → 天符 → 青龙 → 咸池 → 太阴 → 天乙
- 八门：休、生、伤、杜、景、死、惊、开（**仅"门"与时家相同**）
- **不用八神** —— 改用**黄道黑道、喜神、贵神**（神煞体系，**与奇门八神不同**）

> 实现要点：
> 1. 日家不能复用 `NineStarsEnum`，需要新建 `RiJiaStarEnum`（详见 `extra_hour_plans.md` §4.6）。
> 2. 日家盘的 `EachGong.god` / `diGod` 字段在 Phase 2 内**置空或占位**；完整的"黄道黑道喜神贵神"体系作为后续单独 Phase（不在本期范围）。

## 1b. 不布三奇六仪（对照表 §三）

**日家不布三奇六仪地盘**，无地盘奇仪，纯九宫门 + 星。
工程上：日家盘的 `EachGong.diPan` / `tianPan` / `tianPanAnGan` / `renPanAnGan` / `yinGan` 等天干字段均**置空或占位**，UI 渲染时按家维度跳过。

## 1c. 无值符 / 无值使（对照表 §四）

日家**无值符、无值使**概念，**以休门为纲**。
工程上：日家盘的 `QiMenPan.zhiFuStar` / `zhiShiDoor` 字段需以**休门**为占位（或干脆 nullable）。详见 `ri_jia_tasks.md` P2-T5.4。

### 「3 日同宫」语义

每行的每一项（如「甲子」）代表 60 甲子日序里**以该日为首的 3 日组**，例如「甲子」覆盖 甲子(1) → 乙丑(2) → 丙寅(3)。
20 组 × 3 日 = 60 日，正好覆盖一甲子周期。

### 编程实现伪码

```dart

final table = yinYangDun.isYang ? yangDunXiuMenMap : yinDunXiuMenMap;
int xiuMenGongNumber = table[groupKey]!;
```

## 4. 顺逆布八门

| 日干（天干阴阳） | 排门方向与顺序 |
| --- | --- |
| 阳干（甲、丙、戊、庚、壬） | **顺时针**：休 → 生 → 伤 → 杜 → 景 → 死 → 惊 → 开 |
| 阴干（乙、丁、己、辛、癸） | **逆时针**：休 → 开 → 惊 → 死 → 景 → 杜 → 伤 → 生 |

中 5 宫：**寄坤 2 宫**，无门。

## 5. 排日家九星（一日一星，顺飞）

九星顺序：太乙(1) → 摄提(2) → 轩辕(3) → 招摇(4) → 天符(5) → 青龙(6) → 咸池(7) → 太阴(8) → 天乙(9)

算法：
1. 计算当日距最近**甲子日**的天数 `d`。
2. 起始宫：阳遁 = 坎 1（太乙起坎）；阴遁 = 离 9（太乙起离）。
3. 九星顺飞：宫号 = ((起始宫号 − 1 + d) mod 9) + 1；**不入中 5**。

## 6. 吉凶判定

- 三吉门：**休、生、开**（落宫为吉）
- 日家九星：
  - 吉：**太乙、青龙、太阴**
  - 凶：**咸池、天符**

## 7. 与时家的结构性差异

| 维度 | 时家 | 日家 |
| --- | --- | --- |
| 盘法 | 转盘 | **飞盘** |
| 用星 | 北斗九星（蓬芮等） | **日家九星（太乙等）** |
| 起符机制 | 时干→旬首→值符（gan-driven） | **距甲子日天数顺飞**（day-count-driven） |
| 三奇六仪地盘 | 必须排 | **不布三奇六仪** |
| 值符 / 值使 | 必有 | **无**，以休门为纲 |
| 八神 | 必用（值符螣蛇等） | **不用**，改用黄道黑道喜神贵神 |
| 阴阳遁来源 | 节气 | 节气 |
| 起局 | 节气三元 5 天一局 | 3 日一局，日柱定休门宫 |
