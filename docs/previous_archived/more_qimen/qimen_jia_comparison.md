## 一句话极简总结

1. **只有时家是转盘，日 / 月 / 年全是飞盘**
2. **月家 = 年家**：星、门、神、排盘规则完全一样，只时间尺度不同
3. **日家独立**：九星独一套、无值符 / 值使、无三奇六仪、不用八神
4. **时、日 有阴阳遁；月、年 只用阴遁**
5. **只有时家能日常一事一占，日家专择吉，年月家看大势**
