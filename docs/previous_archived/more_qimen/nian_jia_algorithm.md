- 八门：同时家、同月家
- 八神：同时家、同月家（飞盘逆排）

## 2. 阴阳遁

**年家只用阴遁**（与月家相同；对照表 §一）。

## 3. 盘法

**飞盘（飞宫法）**，与月家同（对照表 §一）。

## 4. 三元（180 年循环，60 年一元）

| 元 | 年序（元内 1-60） | 起局 |
| --- | --- | --- |
| 上元 | 1 - 60 年 | **阴遁 1 局**，坎 1 起甲子戊 |
| 中元 | 61 - 120 年 | **阴遁 4 局**，巽 4 起甲子戊 |
| 下元 | 121 - 180 年 | **阴遁 7 局**，兑 7 起甲子戊 |

### 当前所在元

**当前下元：1984 - 2043**（阴遁 7 局）。

> ⚠️ 起算锚点（即"上元 1 年 = 公元哪一年"）需在实现时固化为常量。
> 推荐基准：以 1984 年为下元第 1 年反推 → 上元起算年 = 1864；中元起算年 = 1924。
> 实现时建议放在 `lib/utils/nian_jia_san_yuan_anchor.dart` 之类的常量文件，便于后期校正。

## 5. 布地盘三奇六仪（阴遁逆布）

与月家完全相同：起局宫放甲子戊，**九宫逆飞**：戊 → 己 → 庚 → 辛 → 壬 → 癸 → 丁 → 丙 → 乙。
中 5 宫：寄坤 2 宫。

## 6. 定值符与值使（双驱：干 + 支）

1. 找**年干所在旬首**（六甲）
2. 旬首在地盘的落宫 → 该宫本位**北斗九星** = 值符，本位八门 = 值使

### 宫位 ↔ 北斗九星本位

| 宫号 | 九星 |
| --- | --- |
| 1 | 天蓬 |
| 2 | 天芮 |
| 3 | 天冲 |
| 4 | 天辅 |
| 5 | 天禽（中宫，寄坤 2） |
| 6 | 天心 |
| 7 | 天柱 |
| 8 | 天任 |
| 9 | 天英 |

> 八门本位与月家同（参考 `yue_jia_algorithm.md` §6 表格）。

## 7. 排天盘九星（值符随年干）

1. 找**地盘年干所在宫** = 目标宫
2. 值符星飞至目标宫
3. 其余九星按九宫**逆飞**：蓬 → 芮 → 冲 → 辅 → 禽 → 心 → 柱 → 任 → 英

## 8. 排人盘八门（值使随年支）

与月家完全相同：值使从本宫起，**逆数到年支宫**；其余八门**逆排**。

## 9. 排神盘八神（小值符随大值符）

与月家完全相同：八神**逆排**（值符 / 螣蛇 / 太阴 / 六合 / 白虎 / 玄武 / 九地 / 九天）。

## 10. 年家 vs 月家：唯一差异

> **核心结论（对照表"一句话总结" §2）：月家 = 年家。星、门、神、排盘规则完全一样，只时间尺度不同。**

唯一差异：

| 维度 | 月家 | 年家 |
| --- | --- | --- |
| 驱动柱 | 月柱（月干 + 月支） | 年柱（年干 + 年支） |
| 三元周期 | 12 年（按年支孟仲季） | **60 年×3 = 180 年** |
| 起局映射 | 孟→坎1 / 仲→兑7 / 季→巽4 | 上元→坎1 / 中元→巽4 / 下元→兑7 |

工程含义：年家 / 月家**共用同一排盘器** `GanZhiDrivenQiMenPan` + 同一星集 `NineStarsEnum`，仅参数化驱动柱、三元映射、起局宫即可。
